# Vocabularies

Controlled-vocabulary lookup tables for CEL maps. A map reads them as `vocab.<name>[<English label>]` and gets back a complete `Concept` node (`id`, `type`, `inScheme`, `prefLabel`). Input fields that take one of these labels are marked with `"x-vocabulary": "<table>"` in their `input-fields/schema.json`, so a wrong label is an input error and a form can show the labels as a dropdown. See [CEL mapping](../../specifications/cel-mapping.md).

`countryCode` maps the same country labels to ISO 3166-1 alpha-3 codes (`Slovenia` → `SVN`), for formats without linked data.

The files are generated by [`build-vocabularies.js`](../../.github/scripts/build-vocabularies.js) (`npm run build-vocabularies`). Do not edit them by hand.
