# Vocabularies

Controlled-vocabulary lookup tables for CEL maps. A map reads them as `vocab.<name>[<English label>]` and gets back a complete `Concept` node (`id`, `type`, `inScheme`, `prefLabel`). A label that is not in the table is a map error. See [CEL mapping](../../specifications/cel-mapping.md).

The files are generated by [`build-vocabularies.js`](../../.github/scripts/build-vocabularies.js) (`npm run build-vocabularies`). Do not edit them by hand.

| Table | Concept scheme | Source |
|---|---|---|
| `country` | `http://publications.europa.eu/resource/authority/country` | ELM `country.xsd` |
| `language` | `http://publications.europa.eu/resource/authority/language` | ELM `language.xsd`, the 24 EU official languages only, keyed by ISO 639-1 code (`en`) |
| `fileType` | `http://publications.europa.eu/resource/authority/file-type` | ELM `file-type.xsd` |
| `encoding` | `http://data.europa.eu/snb/encoding/25831c2` | ELM `europass-content-encoding-types.xsd` |
| `credentialProfile` | `http://data.europa.eu/snb/credential/25831c2` | ELM `europass-credential-types.xsd` |
| `learningMode` | `http://data.europa.eu/snb/learning-assessment/25831c2` | ELM `europass-modes.xsd` |
| `assessmentType` | `http://data.europa.eu/snb/assessment/25831c2` | ELM `europass-learning-assessment-types.xsd` |
| `creditSystem` | `http://data.europa.eu/snb/education-credit/25831c2` | ELM `credit-points.xsd` |
| `eqf` | `http://data.europa.eu/snb/eqf/25831c2` | ELM `eqf.xsd` |
| `supervision` | `http://data.europa.eu/snb/supervision-verification/25831c2` | EU Vocabularies SPARQL endpoint |

ELM XSDs are read from [European-Learning-Model](https://github.com/european-commission-empl/European-Learning-Model) at commit `9d7c5d2` (`xsd/loq/cv/`).
